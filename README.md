# LanP2P-Danmaku 局域网P2P离线弹幕工具
纯C Win32原生开发、无服务端、无需外网，同一局域网Windows设备互相发送置顶滚动弹幕。

## 📌 项目简介
一款轻量化Windows桌面弹幕工具，全程**离线局域网通信**，不需要互联网、不用搭建服务器，所有电脑地位平等（去中心化P2P）。
程序后台托盘常驻，占用极低CPU/内存；支持群发/点对点单发、自定义弹幕颜色/字号/速度。

同时是完整实战学习案例：包含Win32窗口、分层透明弹幕、系统托盘菜单、UDP广播套接字、多线程、临界区、链表管理、资源编译全套原生Windows API代码。

## ✨ 核心特性
### 网络通信
- 完全离线运行，断外网不影响收发弹幕
- UDP广播自动探测局域网所有在线节点，一键刷新设备列表
- 两种发送模式：全员群发 / 指定IP点对点单发
- 自定义UDP私有协议传输弹幕样式与文本
- 修复虚拟网卡IP错位：接收端从数据包源地址读取真实IP，来源精准无误
- 临界区保护在线设备链表，多线程读写无崩溃

### 弹幕渲染
- 分层透明置顶窗口（WS_EX_LAYERED），背景纯透明不遮挡桌面、游戏、视频
- 7种文字颜色、4档字号、4档滚动速度自由搭配
- 2px黑色环绕描边文字，任何壁纸下清晰可见
- 每条弹幕独立窗口，独立存储样式参数，互不干扰
- 弹幕从右向左自动滚动，滑出屏幕自动销毁释放内存

### 交互体验
- 程序启动无主窗口，后台驻留系统托盘，自定义托盘图标
- 右键托盘快速打开弹幕控制台、退出程序
- 输入框回车快速发送，发送后自动清空内容并聚焦输入框，连续发送更方便
- 拦截空白弹幕，不发送无效UDP数据包
- 控制台窗口居中、支持最小化、关闭
- 托盘图标加载失败弹窗提示，方便排查资源问题

### 开发优势
- 纯C语言 + 原生Win32 API，无第三方框架、无闭源依赖
- MinGW64 一键编译，无需VS大型IDE
- 无广告、无后台上传、无隐私收集，本地纯运行
- 代码注释清晰，可自由二次修改扩展

## ⚙️ 编译教程（MinGW64）
### 1. 环境准备
安装 MinGW64，配置环境变量，确保 `gcc`、`windres` 命令可直接在CMD调用。

### 2. 资源文件 resource.rc
```rc
#define IDI_MAIN_ICON 100
#include <windows.h>
IDI_MAIN_ICON ICON "icon.ico"
```

### 3. 编译命令（CMD进入项目目录执行）
```bash
# 编译图标资源
windres resource.rc resource.o

# 链接编译Windows窗口程序
gcc main.c resource.o -o danmaku.exe -lws2_32 -lgdi32 -luser32 -mwindows
```
- `-mwindows`：生成无黑框窗口程序
- 编译完成后目录生成 `danmaku.exe` 可直接运行

## 🚀 使用步骤
1. **组网**：所有电脑连接同一个WiFi/局域网，临时关闭Windows防火墙（防火墙拦截UDP广播会搜不到设备）
2. **启动**：双击 `danmaku.exe`，程序自动后台托盘运行
3. **打开控制台**：右键右下角托盘图标 → 发送弹幕控制台
4. **刷新设备**：点击「🔍 搜寻节点」扫描局域网全部在线电脑
5. **选择发送对象**：下拉可选全员群发 / 单台设备点对点发送
6. **自定义弹幕样式**：调整颜色、字号、滚动速度
7. **发送弹幕**：输入文字后点击「发射」或直接按回车发送
8. 目标设备屏幕自动弹出置顶滚动彩色弹幕

## ❓ 常见问题
1. **搜不到其他电脑**
   全部设备同一局域网；关闭系统防火墙、杀毒网络防护；重新搜寻节点。
2. **弹幕显示IP和本机ipconfig不一致**
   已修复，接收端读取UDP数据包真实源IP，不再读取虚拟机虚拟网卡地址。
3. **自己发的弹幕本机看不到**
   设计逻辑：仅接收其他设备弹幕，本机发送不本地渲染，属于正常效果。
4. **托盘不显示自定义图标**
   确认icon.ico与rc同目录；ID统一为100；编译命令必须携带resource.o。
5. **能否多开程序？**
   不建议，固定占用12345端口，多开会端口冲突、弹幕重复。
6. **断外网能用吗？**
   完全支持，仅依赖内网局域网，不需要互联网。
